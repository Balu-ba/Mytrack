# Домашний фитнес-трекер

Программа на **12 недель**: только вес тела, каждый день.
Цель — похудение + объём мышц.

## Файл

`Домашний_фитнес_трекер_12_недель.xlsx`

| Лист | Зачем |
|------|--------|
| Старт_и_правила | Как пользоваться |
| Упражнения | Техника |
| Программа_12_недель | Цифры по неделям |
| Трекер_тренировок | Сюда ставь «Да» по упражнениям |
| Сводка_по_дням | Авто: день закрыт, когда все упражнения «Да» |
| Замеры_тела | Вес и обхваты |
| Питание_кратко | Еда под цель |

## Старт

- Дата: **10.07.2026** (пятница) — день «Ноги»
- Отжимания ~10, приседания ~20, планка ~30 сек

## Неделя

Пн Верх → Вт Ноги → Ср Пресс и спина → Чт Верх → Пт Ноги → Сб Круговая → Вс Лёгкий день

Недели **4 / 8 / 12** — разгрузка.

## Пересобрать

```bash
python3 generate_tracker.py
```
