# Приложение на телефон (PWA)

Папка `pwa/` — сайт-приложение для iPhone.

## Запуск на компьютере

```bash
cd pwa
python3 -m http.server 8765
```

Узнай IP Mac (Wi‑Fi → настройки, или `ipconfig getifaddr en0`).

На iPhone в **Safari** открой:
`http://ТВОЙ_IP:8765`

Телефон и Mac должны быть в одной Wi‑Fi сети.

## На экран «Домой»

1. Safari → Поделиться  
2. «На экран „Домой“»  
3. Добавить  

Откроется как приложение без строки браузера.

## Что внутри

- **Сегодня** — упражнения, крупные галочки пальцем  
- **Неделя** — статус дней (≥80% = Да)  
- **Замеры** — вес и обхваты  
- **Ещё** — инструкция и сброс  

Данные хранятся в телефоне (localStorage).
